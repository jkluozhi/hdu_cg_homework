## 同日：Release 链接失败（LNK2026 SAFESEH）
- 现象：VS 切 Release|Win32 构建失败，17 个 `LNK2026 模块对于 SAFESEH 映像是不安全的`（opengl32/glu32/glut32.lib），LNK1281 无法生成映像 → 没有 Release exe，用户描述为"崩溃"。
- 根因：课程老版 GL 导入库无 SAFESEH 数据，VS Release|Win32 默认 /SAFESEH 拒绝链接。Debug 不触发。
- 修复：`3d.vcxproj` 两个 Win32 配置的 Link 加 `<ImageHasSafeExceptionHandlers>false</...>`（= /SAFESEH:NO）——用户已自行加上，我验证过无需再改；命令行复现：/SAFESEH 必现 LNK2026+LNK1281，/SAFESEH:NO 链接成功。
- 输出目录在解决方案级：`CG_framework\Release\3d.exe`；GLUT32.DLL 已从 Debug 复制到 Release。
- 注意：VS 解决方案在上一层目录 `CG_framework\`，含多个课程小项目（axia、fillPolygon 等）。
