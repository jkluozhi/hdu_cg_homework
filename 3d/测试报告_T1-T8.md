## T1 变换顺序

输入 `P=(1,2,3)`，先 `scale(2,1,0.5)` 再 `translate(1,-1,2)`。

```
中间: (2,2,1.5)   最终点 = (3, 1, 3.5)
```

预期 (3,1,3.5)，**通过**。说明矩阵是左乘累积、顺序正确。

## T2 默认相机

`E=(0,0,6) C=O Up=(0,1,0)`，`P=(1,1,1)`。

```
透视: view=(1,1,-5)  w=z_v/d=2.5  x_p,y_p=(0.4,0.4)  像素=(50,50)
正交: view=(1,1,-5)  w=1          x_p,y_p=(1,1)      像素=(125,125)
```

透视 `1×(-2)/(-5)=0.4` 正确；正交保持世界单位 1，乘以 gScale=125 后为 125 像素。**通过**。

## T3 移动相机

`E=(4,0,0) C=O Up=(0,1,0)`，`P=(1,2,3)`，`d=-2`。

```
n=(1,0,0) u=(0,0,-1)
view=(-3,2,-3)  透视 x_p,y_p=(-2,1.333)  像素=(-250,166.7)
```

视图基向量与预期完全一致；透视投影 `x_p = -3×(-2)/(-3) = -2`、`y_p = 2×2/3 = 1.333`。**通过**。

## T4 深度与线段长度

视图坐标线段 `x:-1→1, y=0`，分别放在 `z_v=-4` 和 `z_v=-8`。

```
[正交] d=-2
    z_v=-4  长度=2
    z_v=-8  长度=2
[透视] d=-2
    z_v=-4  长度=1     (x_p=-0.5 .. 0.5)
    z_v=-8  长度=0.5   (x_p=-0.25 .. 0.25)
```

透视严格按 `d/z_v` 等比缩放，比 2:1；正交与深度完全无关。**通过**，与作业标准答案（透视 1 和 0.5、正交都是 2）一致。

## D1 改变投影平面距离 d

d 从 −2 改到 −4（映射固定）。

```
[正交] d=-4:  z_v=-4 长度=2      z_v=-8 长度=2
[透视] d=-4:  z_v=-4 长度=2      z_v=-8 长度=1
```

两条线段长度**同时翻倍**（1→2、0.5→1），比例仍是 2:1。结论：**d 只改变透视的整体放大倍数，不改变远近压缩关系；正交公式里根本没有 d，所以数值一字不变**。**通过**。

## T5 裁剪

投影边 `(3,1)→(5,1)`，`gScale=125`。

```
default map 像素: (375,125)->(625,125)
  窗口 [-500,500]x[-500,500]          裁后 (375,125)->(500,125)
  窗口 [0,800]x[0,600] 换算 x[-400,400]y[-300,300]
                                      裁后 (375,125)->(400,125)  长度 250 -> 25
```

Liang-Barsky 裁剪生效。**注意**：作业写的 `[0,800]×[0,600]` 是左下角原点坐标系，`gluOrtho2D` 把原点放在中心，必须换算成 `x∈[-400,400]`、`y∈[-300,300]` 再喂给 `gClip*`。**通过（含坐标系换算）**。

## T6 退化情形

```
E=C:          n=(0,0,0) -> view=(0,0,0), projectPoint=0 (整段丢弃)
Up 平行于 n:  u=(0,0,0) -> view=(0,0,-5), projectPoint=1, 投到 (0,0)
z_v=0:        view=(1,0,0), projectPoint=0 (除零，整段丢弃)
```

三种都不崩溃、不产生 inf/nan，但**没有任何提示输出**。其中 `Up ∥ n` 最隐蔽：它不报错，只是把整个模型压成一个点，画面上看起来像"什么都没画"。若要满足作业 "Give a diagnostic for each"，需在 `viewMatrix()` / `projectPoint()` 加 3 处判断（约 6 行）。

## T7 端点在投影平面背后

```
端点A z_v=-2: ok=1 -> (0,0)
端点B z_v=+1: ok=0 (在投影平面背后)
策略: 任一端点不可投影 -> 整条线段不画
```

除法之前先判定，符合 "Report unsupported 3D inputs before division"。**通过**。
