# 2026-11-26

## Project1（3D→2D 管线）链接失败修复
- 现象：5 个 cpp 全部编译通过，链接报 `LNK2026 opengl32.lib/glu32.lib/glut32.lib 模块对于 SAFESEH 映像不安全` + `LNK1281 无法生成 SAFESEH 映像`（Release|Win32）。
- 原因：工程 AdditionalLibraryDirectories 指向课程老库 `编程实践环境\OpenGL\LIB`，其中的 opengl32.lib/glut32.lib 是 2000 年代产物，不含 /SAFESEH 标记；Win32 默认开启 SAFESEH。
- 修复：`Project1.vcxproj` 的 Debug|Win32 与 Release|Win32 的 `<Link>` 加 `<ImageHasSafeExceptionHandlers>false</ImageHasSafeExceptionHandlers>`（即 /SAFESEH:NO）。
- 环境限制：本机 Bash/PowerShell 对含 MSBuild / devenv 的命令被安全策略拦截，无法命令行验证构建，需在 VS 里重建。
- 提醒：exe 输出到 `CG_framework\Release\`，运行需把 glut32.dll 放到 exe 同级目录（课程包 OpenGL\DLL 里有）。
